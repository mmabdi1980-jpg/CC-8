# CSS Framework

A responsive webpage built using a **CSS framework such as Bootstrap or Foundation** to simplify styling and layout.

* **Responsive Layout:** Adapts to desktop, tablet, and mobile screens.
* **Components:** Uses pre-built buttons, grids, navigation, and cards.
* **Consistency:** Provides a clean and consistent design.
* **Efficiency:** Reduces the amount of custom CSS required.
